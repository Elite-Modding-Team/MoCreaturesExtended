# Mo' Creatures Extended Changelog (12.4.9+)
## 12.4.9
### Update Notes
First version to utilize the new changelog!
### Added
- Added a config option to completely disable Fine Silver.
- Wyvern Egg drops are now affected by Looting (+5% per level).
- Added missing breeding mechanics to the following animals:
  - Birds (Seeds)
  - Boar (Wheat)
  - Bunny (Carrots or Golden Carrots)
  - Deer (Wheat)
  - Duck (Seeds)
  - Goat (Wheat)
  - Turtle (Sugar Canes)
- Birds, Ducks, and Turtles now have baby counterparts.
### Changed
- Wyvwood Doors and Wyvwood Trapdoors now have unique textures (thanks to Tomanex!).
- Each Hunter mob will now attack a variety of different prey!
- Piranhas, Anglerfish, and Snakes are no longer hostile to players, but remain neutral.
### Fixed
- Fixed OreDictionary registries and OreDictionary registration errors.
- Fixed Filch Lizards not dropping stolen items in bulk.
- Fixed Cyan Kitty Bed and Light Blue Kitty Bed textures being swapped.
- Fixed Tall Wyvgrass item model.
- Fixed a crash caused by Lycanites Mobs fluids damaging aquatic mobs.
- Fixed certain MoC mobs moving at an incredibly fast speed while around water.
- Fixed bugged baby turkey model.
- Fixed Big Golems being almost unkillable.
- Fixed buggy swimming behavior on all MoC land mobs.
- Fixed reversed head tilting on several MoC mobs.
- Fixed Hunter mobs always attacking the player on sight.
- Fixed leaves from Wyvwood trees immediately despawning after breaking at least one.
- Significantly improved Wyvwood tree performance.
- Fixed a potential memory leak with Wyvwood trees.
- Fixed a potential crash caused by Wyvwood tree generation.
### Removed
- Removed some outdated and unimplemented content.
